S3는 단순한 스토리지 서비스가 아니다. 그 중 웹 호스팅 기능이 유용하다. 이 기능을 사용하면 S3에서 생성한 버킷을 그대로 웹 사이트로 사용할 수 있다. 

>1. 웹 사이트 호스팅이란
>	S3는 정적 웹 사이트를 호스팅할 수 있다. 정적 웹 사이트란 서버가 스크립트를 처리하지 않는 사이트를 말한다. 정적 웹 사이트에는 자바 스크립트와 같은 클라이언트에서 처리하는 스크립트를 포함할 수 있다. 반대로 동적 웹 사이트란 서버에서 처리하는 언어가 포함된 사이트를 말한다. 
>	정적 웹 사이트를 호스팅하려면 버킷을 그대로 웹 사이트로 오픈하면 된다. URL을 설정하고 버킷에 누구든지 접속할 수 있도록 하면 된다. 

>2. 웹 호스팅에 필요한 설정
>	버킷을 웹 사이트로 사용하려면 버킷을 생성할 때와 생성한 후에 몇가지 설정을 해야한다. 
>	+ 정적 웹 호스팅을 활성화한다. 
>	+ 공용 액세스 차단을 해제한다.
>	+ 버킷 정책을 '모든 사용자'로 설정한다. 
>	+ 버킷명을 사용할 도메인명으로 지정한다. 
>	+ 개인 도메인을 소지한 경우는 DNS 서비스를 사용하여 설정한다. 

>3. 다른 서비스로 구축한 웹 호스팅과의 차이
>	AWS에는 웹 사이트 구축을 위한 몇가지 서비스가 있다.
>	+ Amazon Lightsail: 필요한 기능을 선택하면 웹 사이트에 필요한 서비스 전체를 정해진 가격으로 구축할 수 있는 서비스이다. EC2와 달리 유연성은 없다. 변경해야 할 때는 스냅샷이라고하는 기능을 이용하여 백업하고,변경하고 싶은 사양의 Lightsail을 새로 계약하여 백업에서 복원하는 작업을 수행한다. 
>	+ AWS Amplify: 웹을 개발하기 위한 도구 전체를 제공하는 서비스로 개발자를 대상으로 한다. 자바스크립트로 AWS의 다양한 기능을 호출하여 시스템을 구축한다.
